# Zhivnost Panely — Трекер манги и манхвы

Веб-приложение для отслеживания прочитанной манги, манхвы и другого контента. Позволяет вести личную коллекцию тайтлов, отмечать прогресс чтения по томам и управлять статусами.

---

## Технологии

- **PHP** ≥ 5.6
- **Yii2 Framework** (Basic Template)
- **MySQL** — база данных `panely_site`
- **Bootstrap 4** — верстка интерфейса
- **jQuery** — AJAX-взаимодействие

---

## Структура базы данных

| Таблица             | Описание                                                     |
|---------------------|--------------------------------------------------------------|
| `manga`             | Список тайтлов (название, описание, обложка, тип)            |
| `volume`            | Общее количество томов для каждого тайтла                    |
| `reading_progress`  | Прогресс чтения пользователя (текущий том, статус)           |
| `user`              | Зарегистрированные пользователи                              |
| `role`              | Роли пользователей (1 — администратор, остальные — обычные) |
| `wishlist`          | Список желаемого пользователя                                |

## Установка и запуск

### 1. Требования

- OpenServer / XAMPP / WAMP с PHP и MySQL
- Composer

### 2. Клонирование и установка зависимостей

```bash
cd C:\OpenServer\domains\zhivnostpanely
composer install
```

### 3. Настройка базы данных

Откройте файл `config/db.php` и укажите параметры подключения:

```php
return [
    'class' => 'yii\db\Connection',
    'dsn'      => 'mysql:host=localhost;dbname=panely_site',
    'username' => 'root',
    'password' => 'root',
    'charset'  => 'utf8mb4',
];
```

Создайте базу данных `panely_site` в MySQL и выполните SQL-миграции (или импортируйте дамп, если он есть).

### 4. Настройка URL

В `config/web.php` включён `enablePrettyUrl` — убедитесь, что сервер поддерживает `mod_rewrite` (Apache) или аналог для Nginx. Файл `web/.htaccess` уже настроен.

### 5. Права доступа к папкам

```bash
chmod 777 runtime/
chmod 777 web/assets/
chmod 777 web/images/
```

### 6. Открытие в браузере

```
http://zhivnostpanely/
```

## Как это работает

### Роли пользователей

| `ID_role` | Роль          | Возможности                                      |
|-----------|---------------|--------------------------------------------------|
| `1`       | Администратор | Полный доступ: CRUD манги, управление пользователями |
| Остальные | Пользователь  | Просмотр, отслеживание прогресса, список желаний |

Любой может зарегистрироваться через `/site/register`. Гостям доступен просмотр в режиме «демо» (используется пользователь с `ID_user = 1`).

---

### Страницы и маршруты

| URL                         | Контроллер / Действие        | Описание                                     |
|-----------------------------|------------------------------|----------------------------------------------|
| `/`                         | `SiteController::actionIndex`| Главная — статистика, новинки, «продолжить чтение» |
| `/site/manga?id=X`          | `SiteController::actionManga`| Страница тайтла, установка статуса чтения    |
| `/site/progress`            | `SiteController::actionProgress` | Список всего прогресса чтения пользователя |
| `/site/search`              | `SiteController::actionSearch` | Поиск и фильтрация манги                   |
| `/site/profile`             | `SiteController::actionProfile` | Профиль пользователя                       |
| `/site/login`               | `SiteController::actionLogin`| Вход в систему                               |
| `/site/register`            | `SiteController::actionRegister` | Регистрация                              |
| `/site/inc-progress?id=X`   | `SiteController::actionIncProgress` | +1 том к прогрессу (AJAX или redirect) |
| `/admin`                    | `AdminController::actionIndex` | Панель администратора (только для админов) |
| `/admin/create`             | `AdminController::actionCreate` | Добавить новый тайтл                      |
| `/admin/update?id=X`        | `AdminController::actionUpdate` | Редактировать тайтл                       |
| `/admin/delete`             | `AdminController::actionDelete` | Удалить тайтл (POST)                      |
| `/admin/users`              | `AdminController::actionUsers` | Управление пользователями                  |
| `/admin/change-role`        | `AdminController::actionChangeRole` | Сменить роль пользователя           |
| `/admin/delete-user`        | `AdminController::actionDeleteUser` | Удалить пользователя                |

### Прогресс чтения

Статусы, которые можно присвоить тайтлу:

- **Читаю** — в процессе
- **Прочитано** — завершено (устанавливается автоматически при достижении последнего тома)
- **Отложено** — на паузе
- **Буду читать** — запланировано

Кнопка **«+1 том»** отправляет AJAX-запрос на `/site/inc-progress?id=X`. Если текущий том достигает общего числа томов, статус автоматически меняется на «Прочитано».

---

### Загрузка обложек

При создании или редактировании тайтла в админ-панели можно загрузить файл обложки (PNG, JPG, JPEG, WEBP, SVG). Файл сохраняется в `web/images/` с уникальным именем вида `manga_<uniqid>.ext`. Если обложка не загружена — используется логотип сайта.

---

### Поиск и фильтрация

На странице `/site/search` можно искать тайтлы:
- **по названию или описанию** (строка запроса `q`)
- **по типу** (Манга, Манхва и т.д.) — чекбоксы
- **по статусу чтения** — фильтр по своей коллекции

---

### Панель администратора

Доступна только пользователям с `ID_role = 1`. При попытке зайти без прав — показывается ошибка «Доступ запрещён». При попытке незалогиненного пользователя — редирект на `/site/login`.

Возможности администратора:
- Просмотр статистики (всего тайтлов, пользователей, томов, записей прогресса)
- Поиск и листинг манги с пагинацией (15 записей на страницу)
- CRUD для тайтлов (создание, редактирование, удаление)
- Управление пользователями: смена роли, удаление (нельзя удалить/разжаловать самого себя)

## Дополнительно

- Пароли хранятся в открытом виде — рекомендуется добавить хеширование через `password_hash()` перед деплоем в продакшн.
- Почта настроена в файловый транспорт (`useFileTransport = true`) — реальные письма не отправляются без дополнительной настройки SMTP.
